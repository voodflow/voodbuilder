# Page templates

The **Templates** library tab lists layouts you can apply to the current page.

## Core capabilities

| Action | Package |
|--------|---------|
| Browse installed / catalog templates | **Core** |
| **Apply** template — replace or append page content | **Core** |
| Install template from URL (when enabled) | **Core** |
| Drag template onto canvas | **Core** |

When applying, choose **Replace** (reset page body) or **Append** (add below existing content).

## Templates Pro companion

| Action | Package |
|--------|---------|
| Save current selection as template | **Templates Pro** |
| JSON import / export | **Templates Pro** |
| Multi-select authoring extras | **Templates Pro** |

Without Templates Pro, those actions show a soft gate with a CTA instead of failing silently.

## Best practices

- Apply templates to **empty pages** when possible — Replace is destructive.
- Templates intentionally **omit nav and footer** — chrome layouts provide site shell.
- After apply, review content width and mobile breakpoints.
