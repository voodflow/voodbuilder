# Companions (later)

VoodBuilder core boots without paid companions. When a feature needs another package, the UI shows a soft-gate / upsell instead of a broken panel.

| Companion | Typical surfaces |
|-----------|------------------|
| **Components** | Save selection as component, library insert, code import, global classes |
| **Dynamics** | Make dynamic, collections / list repeat Pro |
| **Templates Pro** | Template authoring, JSON import/export, multi-select |
| **Popups** | Popup library and public runtime |
| **Forms / Cookie / Analytics** | Productized extensions (scaffolds) |

::: info
This core manual does **not** document companion workflows yet. Each companion will add its own VitePress section and deep links from these stubs.
:::
