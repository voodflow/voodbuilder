# Library & blocks

The left **Library** column has tabs for **Elements**, **Components**, and **Templates**.

## Elements (core)

### Layout

Section, Container, Block, Div — see [Understanding the layout](./understanding-the-layout).

### Section catalog

Sixty-plus marketing sections from the section catalog, adaptive to light/dark via theme tokens, grouped roughly as:

Hero, Features, Content, Articles, CTA, Contact, Shop, Gallery, Stats, Steps, Team, Testimonials, Pricing, Header, Footer, …

### Landing kits

Starter sets (e.g. Landing 01–03) inspired by polished marketing themes, plus page templates that compose them.

### Media

Background image/video, image/video sliders, hero media patterns.

### Site chrome

Navbar, footer variants (multi-column, newsletter, social, centered), and the **chrome content slot** (layouts only).

### Basic & plugin blocks

- Basic layout blocks (when enabled)
- Optional plugins: **forms**, **style background**, **tabs**, **custom code** (config toggles)

## Components & Templates tabs

- **Templates** — browse and **apply** templates (replace or append). Saving / JSON import-export may require the Templates companion.
- **Components** — soft-gated; requires the Components companion + entitlements.

## Pins

Pin frequently used blocks for quicker access (pin/unpin in the library UI).

## Dropzones

Catalog heroes expose roles (`media`, `shade`, `content`, `actions`). Drop text into **copy** zones and CTAs into **actions** — not onto decorative media layers.
