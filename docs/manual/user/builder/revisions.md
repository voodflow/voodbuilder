# Revisions

Core keeps **page revisions** so you can restore earlier saves.

## Using history

1. Open the revisions UI from the editor (History module).
2. Browse previous snapshots.
3. Restore one — confirm before overwriting the current draft.

Maximum stored revisions is configurable by the host (`config/voodbuilder.php` / env).
