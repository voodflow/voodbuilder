# Canvas & toolbar

The center column is the live canvas.

## Top bar

Typical controls:

- **Device breakpoints** — desktop / tablet / mobile
- **Undo / redo**
- **Outlines / drop zones** — visualize structure while building
- **Class hover tip** — inspect Tailwind classes under the pointer
- **Preview**
- **Light / dark** canvas
- **Zoom**
- **Toggle side panels**
- **Save** / **View page** / exit

## Floating component toolbar

When a component is selected, a floating toolbar may offer:

- Select parent
- Drag handle
- Move up / down
- Clone / delete
- Edit image (when applicable)
- Content width (section / content wrapper)
- Copy classes / code helpers
- Context insert (button, text, icon, divider, image, link)

::: tip Screenshot needed

:::

## Drag & drop

- Drag blocks from the library onto highlighted dropzones
- Inner drop slots appear while dragging so you can nest at the end of flex/grid containers
- Managed chrome regions reject page-content drops

## Context menu

Right-click on canvas or structure for insert, clone, delete, and related actions.
