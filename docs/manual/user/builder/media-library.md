# Media library in the builder

When **vmedia** is active, inserting or replacing an image opens the **media browser** instead of the basic file picker.

## Browse anywhere

The left sidebar lists all vault folders and albums (Builder, Events, Library, …). Use **All media** to search the whole library. The grid shows items for the current view; folders include media from child albums.

## Choose upload destination

Before you upload or drop files:

1. Select the **folder or album** where the new file should live (e.g. **Builder**).
2. Check the subtitle under the dialog title and the **Uploads → …** line on the drop zone — they show the resolved path (for folders, usually `Builder/Library`).
3. Upload or drag files; they are stored in that location.

If you stay on **All media**, uploads go to the site **default gallery** (marked *default* in the list).

## After upload

New files appear in the grid and can be selected immediately. Existing vault files remain available from any gallery without re-uploading.

## External URLs

Use **Or paste an external URL** at the bottom when you do not need a vault file.
