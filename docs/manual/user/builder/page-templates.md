# Page templates

The **Templates** library tab lists templates you can apply to the current page.

## Core capabilities

- Browse installed / marketplace catalog entries (when configured)
- **Apply** a template — replace page content or append
- Install from URL (when enabled)
- Drag a template onto the page where supported

## Soft-gated (Templates companion)

- Save selection as template
- JSON import / export
- Multi-select authoring extras

Without the companion, those actions show an upsell instead of failing silently.
