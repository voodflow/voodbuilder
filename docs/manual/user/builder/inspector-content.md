# Inspector — Content

The **Content** tab (right column) shows traits for the selected component.

## Typical controls

- Text, links, button labels
- Image URL + choose/remove via Asset Manager
- Hero background image opacity / fit / position (on section or media role)
- Navbar / footer menu assignments, logo, newsletter, social (chrome)
- Form field settings, tab labels, code block source
- Animated counter / logo cloud / CTA-specific options

Prefer Content-panel media controls over hunting for nested `<img>` nodes under shades.

## Dynamic tab

**Make dynamic** / clear binding / list repeat live under **Dynamic** (and related UI). Full collections workflow is documented with the **Dynamics** companion; without it you may see an upsell.

Global plain-text tags (`{brand_name}`, …) are separate — see [Global text tags](./global-text-tags).

## Layers

Use **Layers** to select deep nodes, rename them, and filter chrome when needed.
