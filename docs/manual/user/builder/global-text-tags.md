# Global text tags

Insert plain-text placeholders that resolve on the public site:

| Tag | Typical value |
|-----|----------------|
| `{current_year}` | Calendar year |
| `{brand_name}` | Brand from settings |
| `{site_name}` | Site title |
| `{site_url}` | Root URL |
| `{logged_username}` | Current user name when logged in |

Use the tag picker in the editor where available, or type the brace syntax into text nodes.

These are **not** the same as Dynamic Data field bindings (CMS/collections). Bindings are covered with the Dynamics companion.
