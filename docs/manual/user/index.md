# User manual

VoodBuilder is a visual page builder for Laravel + Filament sites. You manage pages, menus, and site chrome in the admin panel, then design layouts in the **visual editor**.

## What you can do with core

- Create and publish **site pages** (rich text or visual builder)
- Build nested **navigation menus**
- Design reusable **chrome layouts** (header / content slot / footer)
- Configure **appearance**, brand, SEO, and visual themes
- Edit pages visually: layout, sections, style, fonts, conditions, revisions
- Apply **page templates** from the library (authoring extras may require a companion)
- Use forms, tabs, custom code, and in-canvas image editing
